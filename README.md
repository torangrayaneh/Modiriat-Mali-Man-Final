# مدیریت مالی من — پروژه اندروید

اپلیکیشن فارسی ثبت واریزی و هزینه با ذخیره‌سازی محلی SQLite.

## امکانات این نسخه
- ثبت واریزی و هزینه با تاریخ شمسی (`YYYY-MM-DD`). ارقام فارسی و انگلیسی پذیرفته می‌شوند.
- نمایش خلاصه مالی ماه جاری بر اساس تقویم شمسی.
- گزارش ماهانه بر اساس ماه شمسی (`YYYY-MM`).
- نمایش آخرین تراکنش‌ها و مانده کل ثبت‌شده.
- پیشنهاد عنوان هزینه‌های قبلی و تکمیل مبلغ آخرین هزینه با همان عنوان.
- ذخیره اطلاعات روی گوشی؛ برنامه برای عملکرد اصلی به اینترنت نیاز ندارد.
- عدم درخواست مجوز اینترنت و غیرفعال بودن پشتیبان‌گیری خودکار اندروید از داده‌های برنامه.

## ساخت APK با GitHub Actions
1. محتویات ZIP را در ریشه یک مخزن GitHub بارگذاری کنید؛ فایل‌ها باید مستقیماً شامل `settings.gradle` و پوشه `app` باشند.
2. از بخش **Actions** گردش‌کار **Build Android APK** را اجرا کنید؛ یا یک commit به شاخه `main` بفرستید.
3. پس از پایان موفق اجرا، وارد همان اجرای Workflow شوید.
4. در قسمت **Artifacts** فایل `modiriat-mali-man-apk` را دانلود و از حالت ZIP خارج کنید.
5. فایل `app-debug.apk` را به گوشی منتقل و نصب کنید.

## ساخت با Android Studio
- پروژه را در Android Studio باز کنید و Gradle Sync را انجام دهید.
- نسخه Android Gradle Plugin برابر 8.7.3، Gradle برابر 8.9، JDK برابر 17 و Android SDK Platform 35 لازم است.
- از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** خروجی بگیرید.
- مسیر خروجی: `app/build/outputs/apk/debug/app-debug.apk`.

## نکات مهم
- این پروژه APK امضاشده برای انتشار عمومی تولید نمی‌کند؛ خروجی Workflow نسخه debug است. برای انتشار، باید کلید امضای اختصاصی ساخته و تنظیم شود.
- اطلاعات فقط در حافظه داخلی همان گوشی نگهداری می‌شوند. حذف برنامه یا پاک‌کردن داده‌های آن می‌تواند اطلاعات را از بین ببرد؛ پیش از استفاده واقعی از اطلاعات مهم، نسخه پشتیبان امن جداگانه تهیه کنید.
- هنگام ارتقا از نسخه قبلی برنامه (پایگاه‌داده نسخه ۱)، تاریخ‌های میلادی ذخیره‌شده به‌صورت خودکار به تاریخ شمسی تبدیل می‌شوند. تاریخ‌های نامعتبر قدیمی بدون تغییر باقی می‌مانند.
